==================================================
8. SCORE CALCULATION
==================================================

PASS

Scores are normalized using:

normalized_score =
(score / max_score) * 100

Weighted final score:

final_score =
sum(normalized_score * weight) / sum(weight)

Demo scores were submitted successfully.

Example demo scores:

Innovation          9 / 10
Technical Quality   8 / 10
Impact              9 / 10
Presentation        8 / 10

Calculated final score:

85

16. KNOWN MVP LIMITATIONS
==================================================

The current implementation is optimized for the hackathon demo and is not intended to be production-ready.

Known limitations include:

- Some demo flows use fixed demo event/rubric identifiers.
- Advanced event administration UI is limited.
- Score persistence can be further improved for production use.
- Automated test coverage can be expanded.
- Production deployment configuration can be extended beyond the local Docker database setup.
